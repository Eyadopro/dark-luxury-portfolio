# Dark Luxury Portfolio

Personal portfolio website with a premium dark theme, GSAP animations, React frontend and Node.js backend.

## Structure

```
portfolio/
├── frontend/     # React + Vite + Tailwind + GSAP
└── backend/      # Express + Node.js
```

## Frontend

```bash
cd frontend
npm install
npm run dev
```

## Backend

```bash
cd backend
npm install
cp .env.example .env
npm run dev
```

## Features

- Dark luxurious design (black + gold)
- Smooth GSAP animations + ScrollTrigger
- Fully responsive
- Contact form connected to Node.js API
- Clean component architecture

## Deploy

- Frontend → Vercel
- Backend → Railway / Render
